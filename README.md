### ⚙️ Arquitectura de Servidores, DBA & SysAdmin en Producción

* **Optimización y Tuning de Motores de Datos (DBA):**
  * Control del `Buffer Pool` en Microsoft SQL Server (`max server memory`) para prevenir saturación de RAM física en Windows Server en horas punta.
  * Mitigación de cuellos de botella transaccionales y conflictos de colación (`Modern_Spanish_CI_AS`) vinculando órdenes clínicas con facturación y caja.
  * Persistencia tri-base: orquestación simultánea entre **MS SQL Server (SISGalenPlus)**, **PostgreSQL** y **Oracle Database**.
* **Gestión de Memoria, Kernel & Servicios Nativos:**
  * Despliegue de binarios compilados en Go y Rust como servicios nativos `systemd` en Ubuntu Server 24.04 LTS con huellas de memoria < 5 MB y proxies inversos Apache HTTP.
  * Tuning de memoria virtual en Linux (`vm.swappiness = 10`, `vm.vfs_cache_pressure = 50`) y paginación en Windows Server.
* **Acceso Fuera de Banda (Out-of-Band OOB) & Red Zero-Trust:**
  * Despliegue de túnel cifrado con **Tailscale Subnet Router** enlazado a **KVM sobre IP Tripp-Lite (B020-U16-19-IP)** y PDU administrable para recuperación remota a nivel BIOS/RAID sin exposición pública de puertos.
* **Infraestructura de Redes & Telemetría 24/7:**
  * Segmentación mediante VLANs en switches **Cisco SF300 / Catalyst**, políticas de firewall/NAT/QoS en **MikroTik RouterOS** y monitoreo centralizado en **Zabbix + PostgreSQL**.

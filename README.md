### ⚙️ Arquitectura de Servidores, DBA & SysAdmin en Producción

* **Optimización y Tuning de Motores de Datos (DBA):**
  * Control del Buffer Pool en Microsoft SQL Server (`max server memory`) para prevenir que el motor agote la RAM física de Windows Server y degrade los servicios hospitalarios.
  * Mitigación de cuellos de botella transaccionales en consultas asistenciales de alta concurrencia vinculando órdenes médicas con facturación y caja (`dbo.Atenciones`, `dbo.CajaComprobantesPago`, `dbo.FactCatalogoServicios`).
  * Persistencia tri-base: orquestación simultánea entre **MS SQL Server (SISGalenPlus)**, **PostgreSQL (ACL y auditoría rápida)** y **Oracle Database**.
* **Gestión de Memoria y Kernel Tuning:**
  * Configuración de paginación (*pagefile*) en Windows Server para soportar picos de demanda en horarios asistenciales críticos.
  * Tuning de memoria virtual en Linux: ajuste de parámetros de kernel (`vm.swappiness = 10`, `vm.vfs_cache_pressure = 50`) y gestión de swap dinámico.
* **Acceso Fuera de Banda (Out-of-Band OOB) & Red Zero-Trust:**
  * Despliegue de túnel seguro con **Tailscale Subnet Router** enlazado a un **KVM sobre IP Tripp-Lite B020-U16-19-IP** y PDU administrable.
  * Resolución remota de contingencias a nivel de BIOS/hardware, arreglos RAID y arranques en frío post-cortes de energía sin presencia física en sala y sin exponer puertos hacia Internet.
* **Infraestructura de Redes & Monitoreo 24/7:**
  * Segmentación mediante VLANs en switches administrables Cisco SF300 / Catalyst y routers MikroTik (reglas de firewall perimetral, NAT y colas dinámicas de QoS).
  * Monitoreo distribuido mediante servidor Zabbix migrado a PostgreSQL, supervisando métricas de hardware, espacio en disco, estado de servicios y enlaces de red.

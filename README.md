### ⚙️ Habilidades de Infraestructura, DBA & SysAdmin

* **DBA & Performance Tuning (MS SQL Server / PostgreSQL):**
  * Control y optimización del buffer pool en entornos de producción (`max server memory` acotado para prevenir saturación de memoria RAM física en Windows Server).
  * Mantenimiento preventivo, análisis de planes de ejecución, tuning de consultas y estabilidad transaccional para sistemas de gestión clínica (SISGalenPlus / SIGH).
* **Gestión de Memoria y Paginación:**
  * Dimensionamiento y configuración técnica de archivos de paginación (*pagefile*) en Windows Server para soportar picos de concurrencia asistencial.
  * Tuning de memoria virtual en Linux (creación/administración de `swapfile`, ajuste de directivas de kernel `vm.swappiness` y `vm.vfs_cache_pressure`).
* **Administración de VPS & Servidores Remotos:**
  * Despliegue, securización mediante SSH (autenticación por llave criptográfica pública/privada, deshabilitación de root/passwords) y mantenimiento de VPS propios e infraestructura on-premise.
* **Seguridad y Conectividad Privada:**
  * Interconexión mallada mediante **Tailscale Mesh (VPN)** implementando *Subnet Routing*, evitando la exposición innecesaria de puertos sensibles (RDP, SSH, DB) a internet.
  * Segmentación de redes hospitalarias mediante VLANs y enrutamiento en switches y routers Cisco y MikroTik RouterOS.
